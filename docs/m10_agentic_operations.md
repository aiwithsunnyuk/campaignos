## Product story

CampaignOS is not positioned as a replacement for enterprise marketing
automation infrastructure.

Its portfolio value is demonstrating that a marketing-operations professional
can model the complete campaign lifecycle:

```text
Plan
  -> Segment
  -> Score
  -> Orchestrate
  -> Create Content
  -> Measure
  -> Analyze
  -> Decide
  -> Review
  -> Prepare Action
```

The M10 agentic layer adds a decision-support loop:

```text
Observe -> Analyze -> Decide -> Explain -> Human Approve -> Action Plan
```

## Data and integration boundary

CampaignOS uses synthetic data only.

The application does not claim live connectivity to Oracle Eloqua,
Salesforce, Outlook or other proprietary systems. Enterprise platforms are
represented as domain concepts and workflow boundaries, not accessed directly.

## Demonstration sequence

For a portfolio walkthrough:

1. Open Campaign Planner.
2. Define or inspect campaign intent.
3. Review Lead Scoring.
4. Inspect Journey Orchestration.
5. Review Content Studio.
6. Open Campaign Analytics.
7. Demonstrate Operational Exports.
8. Show Local LLM Campaign Copilot.
9. Open Agentic Campaign Operations.
10. Select a campaign and inspect evidence.
11. Review agent recommendations.
12. Approve or reject a decision.
13. Demonstrate how approval changes execution readiness.

This sequence tells one coherent story from campaign creation through
decision support.
