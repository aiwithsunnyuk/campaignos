# M11.3 Career Personas & Recommendation Intelligence

M11.3 upgrades the Training Growth Hub from keyword-heavy matching to a
deterministic, explainable career-persona model.

## Persona dimensions

The engine considers only explicit profile fields:

- Current background
- Career goal
- Primary interest
- Experience level

It maps those fields to a predefined career persona and then scores programmes
using catalogue metadata.

## Recommendation logic

The ranking rewards:

- Career-goal alignment
- Persona priority category
- Audience fit
- Experience-level fit
- Interest alignment
- Persona-specific foundation programmes

Every recommendation carries human-readable reasons.

## Safety

No sensitive attributes are inferred. No external data is fetched. The engine is
deterministic and catalogue-driven. It does not claim that a programme guarantees
employment, salary, certification outcomes or any other unverified result.
