# M11.2 Training Campaign Creation

M11.2 turns the M11.1 training catalogue/foundation into a usable campaign-creation workflow.

## End-user flow
1. Select a programme.
2. Choose region and channel.
3. Define session date/time and duration.
4. Select audience strategy and CTA.
5. Build a validated campaign draft.
6. Review a synthetic message preview.
7. Hand the approved draft to an authorized communication system outside CampaignOS.

## Governance
CampaignOS does not send WhatsApp/email messages in this portfolio implementation. Real meeting IDs, passwords, phone numbers, access tokens and API credentials must never be committed to the public repository.
